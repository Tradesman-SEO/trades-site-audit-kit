# Try Trades Website Self-Check and share what would make it more useful

This free browser tool is for trade business owners. Check the basics customers need to see, then take away a practical list of improvements.

[Open the tool](https://tradesman-seo.github.io/trades-site-audit-kit/). No coding knowledge, installation or account is needed. Start with the fictional example, or fill in the labelled fields with your own information. An owner-friendly action list you can work through or send to your website supplier.

Feedback about unclear questions, missing practical options or mobile usability is welcome here. Please use fictional information in public examples and keep customer or confidential details out of this discussion.

This is a guided self-check, not an automated site audit. It cannot measure rankings, diagnose technical faults or guarantee more enquiries.
